# meme--emoji 表情包项目

微信表情包创作项目：基于宠物/人物照片素材，使用 AI（Gemini 等）生成表情包，目标发布至微信表情开放平台。

## 目录结构

```
meme--emoji/
├── docs/            # 设计规范与提示词文档
│   ├── 卡通版表情包生成提示词.md
│   ├── 真人版表情包生成提示词.md
│   ├── 微信表情开放平台配套图片设计规范与 AI 提示词指南.md
│   ├── 青璃宠物交接执行说明.md
│   └── 文件归档清单_按时间分组.md
├── tags/            # AI 生成表情图（微信表情_Gemini_01~47.jpg，按生成时间编号）
├── output/          # 成品输出
├── videos/          # 表情演示视频
├── 图片素材/         # 原始素材（按对象分目录）
│   ├── baodi/       # 9 张
│   ├── byf3/        # 9 张
│   ├── qingli/      # 9 张
│   ├── tangyuan/    # 9 张
│   └── 岱青宝宝/     # 20 张
└── 素材/            # 其他素材包
    └── banana_slices/  # 6 个 zip
```
